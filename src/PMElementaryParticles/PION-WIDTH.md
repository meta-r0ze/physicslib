# Charged-pion width

Two-body formula:

```
Γ(π⁺ → μ⁺ν) =
  G_F² f_π² m_π m_μ² (1 − m_μ²/m_π²)² / (8π).
```

E8 decay constant:

```
f_π = v/(Δ² + Δ − χ)
    = v/1890
    ≈ 130.275 MeV
```

Prediction:

```
τ_π ≈ 2.52×10⁻⁸ s
measured ≈ 2.60×10⁻⁸ s
ratio ≈ 0.97
```

So the charged-pion lifetime is about 3% low using E8 inputs only.
