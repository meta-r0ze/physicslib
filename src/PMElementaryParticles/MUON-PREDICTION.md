# Muon lifetime check

Comparison only.

Inputs:

```
G_F from E8 electroweak reference
m_μ from E8 lepton masses
continuum massless-pair phase space (MuonRate)
```

Prediction:

```
Γ_μ = G_F² m_μ⁵/(192π³)
τ_μ ≈ 2.187×10⁻⁶ s
measured ≈ 2.197×10⁻⁶ s
ratio ≈ 0.995
```

The muon works at the 0.5% level using E8 inputs.  The phase-space coefficient
is still the continuum one proved in `MuonRate`; a finite spectral-channel
replacement remains open.
